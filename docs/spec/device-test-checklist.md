# 실기기 검증 체크리스트

현재 코드(HEAD) 기준으로 실기기에서 확인할 항목과 결과. `README.md` 수동 검증 매트릭스가 "무엇을 어떻게 확인하는가"의 정본이고, 이 문서는 **진행 상태와 코드 사전 추적 결과**만 소유한다. 항목이 전부 통과·기록되면 결과를 `README.md`에 옮기고 이 문서는 삭제 후보다.

기기: iPhone 15 Pro (iPhone16,1), iOS 26.6. 결과 표기: ✅ 통과 / ❌ 실패 / ⬜ 미확인. 실패는 어떻게 보였는지를 비고에 적고 `LLM_REPORT.md` 사례 후보로 삼는다.

## 1. 기본 동작

2026-09-04 영상 판독 회차: 사용자가 촬영한 실기기 화면 녹화 5편(각 약 20초)을 1fps 프레임으로 추출해 판정. 결과의 "영상"은 그 근거.

"코드 추적" 열은 실기기 전에 소스에서 시나리오를 따라간 결과 (`LLM_REPORT.md` 사례 12). **성립**은 코드상 그렇게 동작해야 한다는 뜻이지 검증이 아니다.
